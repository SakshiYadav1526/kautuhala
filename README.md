
# Kautuhala Coding Guild Website

## About the Project

Kautuhala Coding Guild is a multi-page website created using HTML5. The website represents a community of curious learners who explore computing, engineering, programming, and technology through projects and experiments.

The main purpose of this project is to provide information about the guild, its members, learning activities, and the process of joining the community.

## Objectives

- To create a multi-page website using HTML.
- To learn the basic structure of an HTML document.
- To connect multiple web pages using hyperlinks.
- To organise information using headings, paragraphs, lists, and tables.
- To use HTML forms for collecting sample user information.
- To include images, audio, video, and SVG graphics.
- To practise semantic HTML and accessible web page structure.

## Technologies Used

- **HTML5** – For creating the structure and content of web pages.
- **Visual Studio Code** – For writing and editing the HTML files.
- **Live Server** – For running and previewing the website locally.
- **GitHub Pages** – For hosting the website online.

## Website Pages

### 1. Home Page (`index.html`)
Introduces Kautuhala Coding Guild, its philosophy, areas of exploration, and learning journey. It also includes images, audio, video, and links to other pages.

### 2. The Guild (`guild.html`)
Explains the meaning of Kautuhala, the guild's core principles, structure, values, and learning progression.

### 3. Members (`members.html`)
Presents guild roles, responsibilities, example member profiles, and areas of technical exploration.

### 4. Quests (`quests.html`)
Displays example projects, the quest lifecycle, project categories, and useful learning resources.

### 5. Join (`join.html`)
Contains a sample membership application form with personal information fields, learning interests, system specifications, and learning preferences.

### 6. Contact (`contact.html`)
Provides contact information, email links, and external resources related to web development and collaboration.

## HTML Concepts Demonstrated

This project demonstrates the use of:

- HTML document structure and metadata
- Headings and paragraphs
- Ordered and unordered lists
- Tables and captions
- Internal and external hyperlinks
- Images and figure captions
- Audio and video elements
- Inline SVG graphics
- Forms, labels, input fields, radio buttons, and checkboxes
- Semantic elements such as `header`, `nav`, `main`, `section`, and `footer`
- Email and telephone links
- Accessibility attributes such as `alt`, `aria-label`, and descriptive labels

## Limitations

- The website uses HTML only and has no custom CSS styling or JavaScript functionality.
- The membership form is a demonstration and does not store or process applications.
- Some images and media require an internet connection.
- Example member profiles and quest entries are illustrative and may not represent active guild activities.
- Contact details should be verified before publishing the website publicly.

## Future Improvements

- Add CSS to improve the visual design and responsiveness.
- Add JavaScript for interactive features and form validation.
- Connect the membership form to a secure backend.
- Add real project details and verified member profiles.
- Improve navigation and accessibility.
- Add more project documentation and learning resources.

## Conclusion

The Kautuhala Coding Guild Website demonstrates how multiple HTML pages can be connected to create an organised website. It provides practical experience with HTML elements, navigation, multimedia, tables, forms, and semantic page structure.

This project serves as a foundation for learning web development and exploring more advanced technologies.
